# Multi-Utility AI Chatbot 🚀

A multi-tool LLM-powered chatbot integrated with an **MCP server** to handle external utilities such as an expense tracker.  
Supports **PDF upload & question answering** using document embeddings and vector search.  
Implements **tool-based reasoning** with LangChain & LangGraph, deployed on **AWS** with Dockerized services and a **Streamlit UI**.

🔗 **Live Demo:** [https://huggingface.co/spaces/arpitmishra917/multi-utility-chatbot ](https://huggingface.co/spaces/arpitmishra917/multi-utility-chatbot )

---

## ✨ Features
- **Multi-Utility Integration**: Connects with external tools (e.g., expense tracker) via MCP server.
- **Document Q&A**: Upload PDFs and query them using embeddings + vector search.
- **Tool-Based Reasoning**: Powered by LangChain & LangGraph for intelligent orchestration.
- **Streamlit UI**: Simple, interactive frontend for chatbot interactions.
- **Cloud Deployment**: Dockerized services deployed on AWS EC2.
- **CI/CD Pipeline**: Automated builds & deployments via GitHub Actions.

---

## 🛠 Tech Stack
- **Languages & Frameworks**: Python, FastAPI, Streamlit  
- **LLM Orchestration**: LangChain, LangGraph, LangSmith  
- **Server & Tools**: MCP (FastMcp)  
- **Database**: Neon Vector DB  
- **Infrastructure**: Docker, AWS EC2  
- **CI/CD**: GitHub Actions
